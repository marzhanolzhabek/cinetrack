# CineTrack

CineTrack is a simple movie discovery and watchlist application built with Flutter.

## Features

- View popular movies
- Open movie details
- View movie posters, genres, and ratings
- Add or remove movies from favorites
- Add or remove movies from the watchlist
- Responsive layout

## Screens

### Home Screen
Displays a list of popular movies using reusable MovieCard widgets.

### Movie Detail Screen
Displays the movie poster, title, rating, genres, and movie information.

## Interactivity

The application uses StatefulWidget and setState() for:

- Favorite button
- Add to Watchlist button

## Flutter Widgets Used

- Column
- Row
- Card
- Stack
- Wrap
- Expanded
- SingleChildScrollView
- Image.asset
- ElevatedButton
- IconButton
